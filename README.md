# 🛒 Monitor de Precios Dinámico

Extensión para navegador desarrollada en **Manifest V3** que permite realizar un seguimiento local de precios en plataformas de comercio electrónico (como MercadoLibre, Amazon y Alibaba), mostrando variaciones en porcentaje y valor real frente a registros históricos.

## 🚀 Características
- **Rastreo local automático:** Almacena los precios de los productos visitados usando `chrome.storage.local`.
- **Comparativa inteligente:** Calcula automáticamente la diferencia porcentual y el valor real frente a registros anteriores o del mes pasado (o el cambio más reciente).
- **Popup interactivo:** Visualiza todos los productos monitorizados y despliega un historial detallado de cambios de precios.

## 🛠️ Tecnologías utilizadas
- JavaScript (ES6+)
- HTML5 & CSS3
- Chrome/Edge Extensions API (Manifest V3)
